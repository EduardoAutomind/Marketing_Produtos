Como o tenant foi isolado

No Loki o tenant não está em label (o label tenant é sempre public) — o valor real vem dentro da linha JSON. A linha tem prefixo INFO  que quebra o parser, então é preciso:

{job="autochecker-backend", environment="prod"}
|= "base_compartilhada"
| pattern "<lvl> <js>" | line_format "{{.js}}" | json
| tenant_schema="base_compartilhada"

Novidade favorável: o api.log agora registra duration_ms e user_email por request — o que viabiliza tempo e usuário sem depender do Sentry.

8Lacunas de observabilidade

[CAMPO AUSENTE — user no worker] — o celery-tasks não loga e‑mail/user_id. Documentos processados por usuário é impossível hoje.

[CAMPO AUSENTE — document_type] — tipo de documento (CT‑e, NF‑e, MDF‑e) não é logado, só schema + UUID. "Tipos por cliente" segue impossível.

[CAMPO AUSENTE — sessão] — sem login/logout; tempo de uso é proxy (janelas ativas + replay amostrado), não medição direta.

Frontend sem tenant confiável — ~196 mil transações com user.email = null; performance do Sentry é do projeto todo, não do tenant.

Retenção Loki ≈ 7 dias — sem comparação mês a mês pelos logs; séries longas só via Sentry ou dashboard fixo.

Ponto cego de integração/API — quem opera por integração/mobile pode não gerar user_email no api.log; a web sub‑representa esses clientes.

9Recomendações de instrumentação (para o dev)

  • Logar user_email/user_id no worker — desbloqueia "documentos processados por cliente/usuário".
  • Logar document_type no pipeline de validação — desbloqueia "tipos de documento por cliente".
  • Emitir evento de sessão (login/logout ou heartbeat de foco) — substitui os proxies por medição real de tempo.
  • Popular Sentry.set_user no backend — permite atribuir erro a cliente.
  • Enviar tag tenant confiável no frontend — recorte de performance/uso por cliente no Sentry.
  • Otimizar documents/?page_size=1000 (~22 s) e reduzir a frequência do polling de unread_count/permissions (57%+ do tráfego).
  • Dashboard fixo no Grafana (uso/cliente, tempo app‑aberto, uploads/views por usuário) para superar a retenção de 7 dias.
